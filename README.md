# ShopWatch
Full-stack SDET automation framework built with Java, Selenium,
TestNG, Cucumber, RestAssured, JDBC, MySQL, and GitHub Actions.

## Tech Stack
- Language: Java 17
- UI Automation: Selenium WebDriver + TestNG
- BDD: Cucumber + Gherkin
- API Testing: RestAssured
- Database: MySQL + JDBC
- Reporting: Allure
- CI/CD: GitHub Actions + Jenkins
